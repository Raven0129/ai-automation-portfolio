## Featured Project

### Python-Based Jira Automation Engine

A production-oriented automation system designed to replace native Jira Automation rules that could not reliably process thousands of operational subtasks.

The system includes:

- Automated task classification and assignment
- Round-robin analyst and approver allocation
- Jira REST API integration
- Confluence-managed assignment pools
- Daily reset and recycle routines
- GitLab-scheduled automation
- Excel operational reporting
- Diagnostic and dry-run tools

**Technologies:** Python, Jira REST API, Confluence API, GitLab CI/CD, Git, Claude, and ChatGPT.
